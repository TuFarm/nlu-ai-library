# UI guidelines

- Primary blue `#1d5fd1`, navy `#12366a`, neutral background `#f5f7fb` and white surfaces.
- Cards use 16–24 px radii, subtle borders and restrained shadows.
- Desktop spacing is 24–52 px; mobile spacing is 16–24 px.
- Interactive kiosk controls are at least 46 px high with clear labels and visible states.
- Vietnamese is required for user-facing text; technical identifiers remain English.
- Use green, amber and red status pills consistently. Amber marks mocked or unfinished work.
- Never leave an empty route. Use `UnderDevelopmentCard` with a friendly explanation, support note and return action.
- At 720 px the sidebar becomes a bottom navigation; grids collapse to one column.
